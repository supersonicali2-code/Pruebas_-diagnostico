Prueba 1.1: Latencia y Pérdida de Paquetes

📖 Instrucción y Comando (CMD):

1. Presiona Win + R, escribe cmd y da Enter.

2. Ejecuta el comando:

ping -t [IP_del_Servidor]
📸 Evidencia:
RED

Prueba 1.2: Conexión de Sockets TCP GeoVision

📖 Instrucción y Comandos (PowerShell / CMD):

1. Abra PowerShell o CMD como administrador para verificar la apertura de puertos del sistema con:

Test-NetConnection -ComputerName [IP_Servidor] -Port [Puerto]

2. Seleccione el tipo de prueba (Interna o Externa) e ingrese de manera manual los puertos a verificar (Ej: 4550, 5550, 10000).

📸 Evidencia:
RED

Prueba 1.3: Inspección de Ancho de Banda (Tráfico Real Mbps)

📖 Instrucción y Comando (Administrador de Tareas):

1. Presiona las teclas Ctrl + Shift + Esc (o ejecuta taskmgr en CMD/PowerShell).

2. Ve a la pestaña Rendimiento y selecciona la interfaz de red para ver en tiempo real el consumo exacto de Subida (Envío) y Bajada (Recepción) en Mbps.

🖥️ CAPA DE HARDWARE FÍSICO
HARDWARE

Prueba 2.1: Diagnóstico de Discos Duros

📖 Instrucción y Aplicación Recomendada:

1. Abra un aplicativo especializado en verificación S.M.A.R.T. y salud de almacenamiento. Se recomienda fuertemente:

  • CrystalDiskInfo: Ideal para evaluar rápidamente temperatura, estado de salud general y horas de encendido de forma clara y limpia.
  • Hard Disk Sentinel o Victoria: Altamente recomendados para análisis exhaustivos, detección de sectores defectuosos, pruebas de superficie y rendimiento real.
HARDWARE

Prueba 2.2: Stress de CPU / RAM / GPU

📖 Instrucción y Guía (Administrador de Tareas):

1. Presione las teclas Ctrl + Shift + Esc para abrir el Administrador de Tareas (o ejecute taskmgr en CMD/PowerShell).

2. Diríjase a la pestaña Rendimiento para verificar el uso sostenido, picos y comportamiento general de CPU, Memoria RAM y Procesador Gráfico (GPU / Codec).

📸 Evidencia:
HARDWARE

Prueba 2.3: Visor de Eventos / Logs Críticos

📖 Instrucción y Herramientas Administrativas:

1. Presione Win + R, escriba eventvwr.msc y presione Enter para abrir el Visor de Eventos (accesible desde las Herramientas Administrativas de Windows).

2. Revise en Registros de Windows -> Sistema / Aplicación para buscar errores críticos o advertencias de hardware.
